# 产品需求 · 实现交接基线

定位：免费、无需登录的 A 股信息研究工具，不是交易执行软件，不保证收益或 AI 正确率。普通股票用户优先，技术状态不占据首页主要位置。

## 功能及验收要求

| 编号 | 模块 | 必须满足的行为 |
|---|---|---|
| P01 | 首页 | 行业矩阵、四周期 TOP50 前五名、自选、实时资讯；点击股票进入详情 |
| P02 | 四周期榜单 | 超短、短线、波段、中长线独立切换；公开真实生成与行情参考时间 |
| P03 | 行情 | 股票名称/代码搜索；显示行情源时间与降级，不把昨日价格标成实时 |
| P04 | 股票详情 | 浮层展示资料、30/60 日均价和可用分时指标，缺失留空；加入自选、问 AI |
| P05 | 自选 | 真实选择列表、取消选择、导入导出、刷新保留；不冒充真实账户持仓 |
| P06 | 资讯 | 个股、行业、市场、全球标签符合内容；原文跳转、主备来源可辨识 |
| P07 | AI研究 | 全市场股票，可选 1–12 个老师画像；显示分步状态、保留失败与来源、最终总结 |
| P08 | 知识素材 | 每老师独立文件夹与授权素材；周度蒸馏只生成审核候选，不自动调策略权重 |
| P09 | 盘前 | 真实交易日历、开盘前自动生成并缓存榜单；冻结截止后不能补造预测 |
| P10 | 盘中 | 定时检查行情、异动及风险；接口失败保留快照并告警，不伪造信号 |
| P11 | 盘后 | 真实收盘价对照冻结榜单、复核与次日条件式计划；缺数据报告不标完整 |
| P12 | 预测证据 | 冻结记录不可变、到期验证可追溯；每组至少 30 条后才披露命中率 |
| P13 | 行业/ETF | 上一美股交易日 ETF 映射为 A 股研究线索，绝非确定性板块涨跌预测 |
| P14 | 量化工具 | 明确内置规则与外部引擎；回测假设、成本及成交约束不能隐瞒 |
| P15 | 风险/运行 | 友好错误、去重告警、源时间、主备与预算状态；原始接口错误不公开 |

## 非目标与边界

本批不增加登录、付费订阅、自动下单、真实券商持仓同步。12 个 Agent 是基于获授权资料的策略画像，不代表原作者本人或官方授权背书。AI 蒸馏不是模型训练，方向评分不是概率，样本门槛不是投资效果保证。

## 上线 Definition of Done

1. 脱敏源码新目录安装、构建、测试成功，可回滚。
2. 真实主备源、行情延迟和降级状态均在页面验证。
3. PC/移动端、搜索/详情/自选/会诊流程以浏览器证据验收。
4. 本地与 Sites 分开连续两个完整 A 股交易日无关键任务中断；不可补造缺观测。
5. AI 调用次数限制有效，金额未知明确标注；源数据与回答分别核验。
6. 未完成项列入交接缺口，不能用需求表代替实现证明。当前缺口见 REPAIR_HANDOFF_2026-09-07.md。
