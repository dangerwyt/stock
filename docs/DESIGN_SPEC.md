# 页面设计规范 · 当前实现与验收

## 信息层级

全站左侧导航、顶部轻量状态栏、深色内容工作区。首页先展示行业热力矩阵和四周期 TOP50，下一行自选与资讯。首页榜单只展示五名，通过四个标签切换及详情入口查看完整榜单。不恢复大块技术日志或主判断说明占首屏。

桌面双列模块，手机单列及底部常用导航。任何屏宽不得固定为某次截图尺寸；使用浏览器视口与容器可用宽度。表格允许组件内部横向滚动，整页不得出现横向溢出。浮层须有可发现关闭入口，避免遮挡发送/停止按钮。

## 视觉与交互

保留 `src/styles.css` 当前配色、字体和间距，不引入另一套样式。数字使用清晰对齐与明确单位；红涨绿跌沿用 A 股展示习惯。行情日期、源时间、旧快照和降级状态不能仅靠颜色区分。

股票统一打开详情浮层，可加入自选和进入 AI 研究。四周期标签有当前选中态。资讯链接打开原文，不伪装内部全文授权。自选导入只接受最多 100 个六位代码并去重，名称等待真实资料补全。

准确率页面使用“方向评分 /100”，不显示为 AI 看涨概率。不足样本用“采集中”，不是 0%。保留证据入口、基准配对样本、时间和非实盘收益说明。

## 必须验证

1. 1440×1000 和 390×844 下逐页检查：首页、TOP50、行情、自选、资讯、AI研究、行业、老师、量化、复盘、准确率、风险、运行状态。
2. 四周期切换、股票浮层、搜索、加入自选、跨标签同步、导入无效代码、刷新保留。
3. 键盘焦点可见，Escape 关闭浮层并恢复触发焦点；窄屏菜单与正文不互相遮挡。
4. 接口失败显示恢复提示或真实旧快照；加载期间不填演示业务数字。
5. 截图加页面错误记录是页面验收证据；不替代真实供应商、AI内容事实核验或两日稳定性验收。
